ESP32 SETUP

Connect your device

  1. Start this server on the laptop connected to the same Wi-Fi as your ESP32.
  2. Find your laptop IPv4 address using ipconfig in Command Prompt.
  3. In the Arduino sketch, set API_URL to http://YOUR_LAPTOP_IP:3000/api/sensor.
  4. Keep the laptop and ESP32 on the same network. Allow Node.js through Windows Firewall if prompted.
  5. Open http://localhost:3000 on the laptop to see readings.
The ESP32 reports occupancy and optional voltage/current/power fields. Do not connect a 5 V sensor output directly to an ESP32 GPIO.
